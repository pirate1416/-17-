# 사용한 NLP 모델의 원리

## 1. LSTM

RNN은 단어를 순서대로 읽으며 은닉 상태를 갱신하지만, 문장이 길어지면 앞쪽 정보가 사라지는 기울기 소실 문제가 있다.
LSTM은 셀 상태(cell state)와 세 개의 게이트로 이를 완화한다.

- **망각 게이트**: 이전 셀 상태에서 무엇을 버릴지 결정
- **입력 게이트**: 현재 입력에서 무엇을 셀 상태에 더할지 결정
- **출력 게이트**: 셀 상태에서 무엇을 은닉 상태로 내보낼지 결정

## 2. BiLSTM (참조 코드의 모델)

순방향 LSTM은 문장을 왼쪽에서 오른쪽으로, 역방향 LSTM은 오른쪽에서 왼쪽으로 읽는다.
텍스트 분류(다 대 일)에서는 순방향의 **마지막** 시점 은닉 상태와 역방향의 **첫** 시점 은닉 상태를 이어 붙여 출력층에 넣는다.
(Keras `Bidirectional(LSTM(..., return_sequences=False))`의 동작)

```
그래픽 → 예쁜데 → 최적화 → 최악 ──▶ h_fwd
그래픽 ← 예쁜데 ← 최적화 ← 최악 ──▶ h_bwd
[h_fwd ; h_bwd] → Dense(1, sigmoid) → 긍정 확률
```

한계: 리뷰 전체가 벡터 하나로 압축되므로, 서로 다른 측면의 감정이 한 판정으로 섞인다.

## 3. Transformer 인코더와 사전학습

BERT 계열 모델은 Self-Attention으로 문장 안의 모든 단어 쌍의 관계를 한 번에 계산한다.
대량의 텍스트로 먼저 사전학습한 뒤, 적은 라벨 데이터로 목적 작업에 파인튜닝한다.

- **BERT의 사전학습 (MLM)**: 입력 토큰의 약 15%를 가리고 원래 단어를 맞힘 → 가려진 15% 토큰에서만 학습 신호를 얻음

## 4. ELECTRA / KcELECTRA (구현에 사용할 모델)

ELECTRA는 **Replaced Token Detection**으로 사전학습한다.

1. 작은 **생성기(Generator)**가 일부 토큰을 그럴듯한 다른 단어로 바꿔치기
   - 예: "그래픽 진짜 예쁨" → "그래픽 진짜 **별로**"
2. **판별기(Discriminator)**가 모든 토큰에 대해 원본인지 교체된 것인지 판정
   - 원본 · 원본 · 교체됨
3. 사전학습 후 판별기를 다운스트림 작업에 파인튜닝

장점: 모든 토큰에서 학습 신호를 얻으므로 같은 계산량으로 MLM보다 효율적이다.

**KcELECTRA**는 네이버 뉴스 댓글과 대댓글 약 17GB(1.8억 문장 이상)로 학습한 한국어 ELECTRA다.
구어체, 신조어, 이모지가 많은 사용자 작성 텍스트에 강해 게임 리뷰에 적합하다.
NSMC(네이버 영화 리뷰) 감성 분류 정확도 91.97% (KcELECTRA-base-v2022).

## 5. 측면 기반 감정 분석 (ABSA)에서의 활용

이번 프로젝트에서는 리뷰를 절 단위로 나누고 측면을 태깅한 뒤,
스팀 리뷰 데이터로 파인튜닝한 KcELECTRA로 **절마다** 감정을 판정한다.
리뷰 단위 라벨로 학습한 모델을 절 단위에 적용하므로, 일부 절은 직접 라벨링해 정확도를 검증한다.
